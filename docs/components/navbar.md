# Navbar

Horizontal and vertical navigation bar.

## Basic usage

<div class="preview">
  <nav class="kit-navbar">
    <a class="kit-navbar-brand" href="#">Brand</a>
    <a class="kit-navbar-item -active" href="#">Home</a>
    <a class="kit-navbar-item" href="#">About</a>
    <a class="kit-navbar-item" href="#">Contact</a>
    <div class="kit-navbar-group">
      <a class="kit-navbar-item" href="#">Login</a>
    </div>
  </nav>
</div>

```html
<nav class="kit-navbar">
  <a class="kit-navbar-brand" href="#">Brand</a>
  <a class="kit-navbar-item -active" href="#">Home</a>
  <a class="kit-navbar-item" href="#">About</a>
  <a class="kit-navbar-item" href="#">Contact</a>
  <div class="kit-navbar-group">
    <a class="kit-navbar-item" href="#">Login</a>
```
