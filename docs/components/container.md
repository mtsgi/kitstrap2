# Container

Centered content wrapper with responsive max-widths.

## Basic usage

<div class="preview">
  <div class="kit-container" style="background: var(--kit-bg-secondary);">
    Container (responsive max-width)
  </div>
</div>

```html
<div class="kit-container">
  Content goes here
</div>
```

## Fluid

Full-width container with no max-width constraint.

<div class="preview">
  <div class="kit-container -fluid" style="background: var(--kit-bg-secondary);">
    Fluid container
  </div>
</div>

```html
<div class="kit-container -fluid">
  Full-width content
</div>
```
