# Typography

kitstrap2 provides typography classes and default element styles.

## Title

The `.kit-title` class creates a large, bold title.

<div class="preview">
  <span class="kit-title">Page Title</span>
</div>

```html
<span class="kit-title">Page Title</span>
```

## Sub

The `.kit-sub` class creates secondary, smaller text.

<div class="preview">
  <span class="kit-sub">Subtitle or description text</span>
</div>

```html
<span class="kit-sub">Subtitle or description text</span>
```

## Default headings

kitstrap2 styles `h1`–`h5` elements with consistent spacing and weight.

<div class="preview">
  <h1>Heading 1</h1>
  <h2>Heading 2</h2>
  <h3>Heading 3</h3>
  <h4>Heading 4</h4>
  <h5>Heading 5</h5>
</div>

```html
<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
```

## Code

Inline `code` and `pre` blocks are styled with a monospace font and subtle background.

<div class="preview">
  <p>Use <code>kit-button</code> for buttons.</p>
  <pre><code>.kit-button {
  display: inline-flex;
}</code></pre>
</div>

```html
<p>Use <code>kit-button</code> for buttons.</p>
<pre><code>.kit-button {
  display: inline-flex;
}</code></pre>
```
