# Tab

Tabbed navigation for panels and content sections.

## Basic usage

<div class="preview">
  <div class="kit-tabbar">
    <a class="kit-tab -active" href="#">Tab 1</a>
    <a class="kit-tab" href="#">Tab 2</a>
    <a class="kit-tab" href="#">Tab 3</a>
    <a class="kit-tab -disabled" href="#">Disabled</a>
  </div>
</div>

```html
<div class="kit-tabbar">
  <a class="kit-tab -active" href="#">Tab 1</a>
  <a class="kit-tab" href="#">Tab 2</a>
  <a class="kit-tab" href="#">Tab 3</a>
  <a class="kit-tab -disabled" href="#">Disabled</a>
</div>
```
