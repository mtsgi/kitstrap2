# ナビバー

水平・垂直ナビゲーションバー。

## 基本的な使い方

<div class="preview">
  <nav class="kit-navbar">
    <a class="kit-navbar-brand" href="#">ブランド</a>
    <a class="kit-navbar-item -active" href="#">ホーム</a>
    <a class="kit-navbar-item" href="#">概要</a>
    <a class="kit-navbar-item" href="#">連絡先</a>
    <div class="kit-navbar-group">
      <a class="kit-navbar-item" href="#">ログイン</a>
    </div>
  </nav>
</div>

```html
<nav class="kit-navbar">
  <a class="kit-navbar-brand" href="#">ブランド</a>
  <a class="kit-navbar-item -active" href="#">ホーム</a>
  <a class="kit-navbar-item" href="#">概要</a>
  <a class="kit-navbar-item" href="#">連絡先</a>
  <div class="kit-navbar-group">
    <a class="kit-navbar-item" href="#">ログイン</a>
  </div>
</nav>
```
