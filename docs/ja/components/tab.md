# タブ

パネルやコンテンツセクションのタブナビゲーション。

## 基本的な使い方

<div class="preview">
  <div class="kit-tabbar">
    <a class="kit-tab -active" href="#">タブ 1</a>
    <a class="kit-tab" href="#">タブ 2</a>
    <a class="kit-tab" href="#">タブ 3</a>
    <a class="kit-tab -disabled" href="#">無効</a>
  </div>
</div>

```html
<div class="kit-tabbar">
  <a class="kit-tab -active" href="#">タブ 1</a>
  <a class="kit-tab" href="#">タブ 2</a>
  <a class="kit-tab" href="#">タブ 3</a>
  <a class="kit-tab -disabled" href="#">無効</a>
</div>
```
