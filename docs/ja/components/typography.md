# タイポグラフィ

kitstrap2はタイポグラフィクラスとデフォルト要素スタイルを提供します。

## タイトル

`.kit-title` クラスで大きく太字のタイトルを作成します。

<div class="preview">
  <span class="kit-title">ページタイトル</span>
</div>

```html
<span class="kit-title">ページタイトル</span>
```

## サブ

`.kit-sub` クラスで補助的な小さいテキストを作成します。

<div class="preview">
  <span class="kit-sub">サブタイトルや説明テキスト</span>
</div>

```html
<span class="kit-sub">サブタイトルや説明テキスト</span>
```

## デフォルト見出し

kitstrap2は `h1`〜`h5` 要素に一貫したスペーシングとウェイトを適用します。

<div class="preview">
  <h1>見出し1</h1>
  <h2>見出し2</h2>
  <h3>見出し3</h3>
  <h4>見出し4</h4>
  <h5>見出し5</h5>
</div>

```html
<h1>見出し1</h1>
<h2>見出し2</h2>
<h3>見出し3</h3>
<h4>見出し4</h4>
<h5>見出し5</h5>
```

## コード

インラインの `code` と `pre` ブロックはモノスペースフォントと控えめな背景でスタイリングされます。

<div class="preview">
  <p><code>kit-button</code> をボタンに使用します。</p>
  <pre><code>.kit-button {
  display: inline-flex;
}</code></pre>
</div>

```html
<p><code>kit-button</code> をボタンに使用します。</p>
<pre><code>.kit-button {
  display: inline-flex;
}</code></pre>
```

## 引用

<div class="preview">
  <blockquote>kitstrap2はkitstrapのモダンな後継フレームワークです。</blockquote>
</div>

```html
<blockquote>kitstrap2はkitstrapのモダンな後継フレームワークです。</blockquote>
```
