# コンテナ

レスポンシブな最大幅を持つ中央寄せコンテンツラッパー。

## 基本的な使い方

<div class="preview">
  <div class="kit-container" style="background: var(--kit-bg-secondary);">
    コンテナ（レスポンシブ最大幅）
  </div>
</div>

```html
<div class="kit-container">
  コンテンツをここに配置
</div>
```

## フルイド

最大幅制約なしの全幅コンテナ。

<div class="preview">
  <div class="kit-container -fluid" style="background: var(--kit-bg-secondary);">
    フルイドコンテナ
  </div>
</div>

```html
<div class="kit-container -fluid">
  全幅コンテンツ
</div>
```
